# comfyui-xiaomo-agnes-video
## 肖默定制 Agnes V2.0 图生视频API节点
专属标识：肖默，适配 Agnes-Video-V2.0 官方异步API，一键自动化工作流，无需拼接多个请求节点

## 功能介绍
1. 图生视频能力，适配新版 apihub.agnes-ai.com 域名
2. 内置帧数规则校验，强制遵循 `8n+1` 规范（81/121/241/441），提前拦截错误参数
3. 自动轮询查询生成进度，排队、渲染全程自动等待，无需手动多次GET请求
4. 界面全节点携带专属标记「肖默」，私有化辨识度高，便于区分自用定制插件
5. 一键输出视频MP4直链，搭配通用下载节点即可保存本地视频文件

# v1.3 安全加固更新说明
## 重要安全更新
1. **移除硬编码敏感凭证**：删除代码中内置的 Freeimage 图床 API 密钥，改为节点可选参数自主配置，彻底杜绝源码分发导致的密钥泄露与额度盗用风险。
2. **移除私有服务域名**：移除专属 Cloudflare Worker 反代地址，新增 `api_create_endpoint` 可自定义接口端点，避免私有服务随开源代码被滥用产生额外费用。
3. **修复SSL验证风险**：默认开启全局 SSL 证书验证，移除所有强制 `verify=False` 配置，消除中间人攻击隐患；同时保留可选关闭开关，兼容特殊网络环境。
4. **统一网络安全策略**：所有 HTTP 请求统一走会话安全配置，图床上传、API 调用、视频下载全链路遵循一致的安全规则。

## 功能优化
1. **图床容灾升级**：12 图床集群新增容错逻辑，未配置密钥的图床自动静默跳过，不会中断整体上传流程，开箱即可使用其余 11 个免密钥图床。
2. **参数分类优化**：新增参数全部归入可选配置项，原有必填参数保持不变，不破坏旧版工作流的使用习惯。
3. **缓存逻辑兼容**：任务缓存、图片缓存机制完全向下兼容，升级后历史任务恢复、图片上传缓存均可正常使用。
4. **错误提示优化**：补充图床失败、接口异常的日志说明，新增网络环境排查指引，便于问题定位。

## 兼容性说明
- ✅ 完全向下兼容旧版节点，原有工作流无需修改任何参数即可直接运行
- ✅ 新增参数均为可选，留空时使用官方默认接口与安全配置
- ✅ 支持自定义代理、自定义接口端点，适配各类网络环境

## 升级注意事项
1. 若需使用 Freeimage 图床，需自行前往 freeimage.host 申请 API Key，填入节点的 `freeimage_api_key` 参数即可
2. 原有自定义反代用户，请将你的代理地址填入 `api_create_endpoint` 参数
3. 如遇 SSL 证书相关报错，可临时勾选 `disable_ssl_verify` 选项，建议优先排查本地网络与证书环境
4. 建议所有用户升级至此版本，避免旧版硬编码凭证带来的安全与费用风险
## V1.2 最新版本


### 🚀 重大优化 - 网络稳定性大幅提升

**主要解决的问题**：
- 修复了 Windows 下常见的 `ConnectionResetError: [WinError 10054] 远程主机强迫关闭了一个现有的连接。`
- 显著提高了长时间视频生成任务（尤其是轮询阶段）的稳定性

### ✨ 新特性 & 改进

- **HTTP 会话全面强化**：
  - 重试次数提升至 12 次
  - 增加连接池（pool_connections=20）
  - 添加 `Connection: keep-alive` 和 `Keep-Alive` 头
  - 扩展重试状态码，覆盖更多服务器错误
  - 更合理的 backoff 退避策略

- **轮询阶段优化**（最重要改进）：
  - 每次轮询使用全新独立 Session，减少连接被服务器强制关闭的概率
  - 最大等待时间延长至 **20 分钟**
  - `poll_interval` 默认值从 5 秒调整为 **8 秒**（更友好）
  - 更完善的异常捕获和重试逻辑，打印更清晰的警告信息
  - 超时时间调整为更合理的 `(20, 90)`

- **下载阶段优化**：
  - 采用 `stream=True` + 分块下载，降低内存占用
  - 使用独立下载 Session

- **其他改进**：
  - 代码结构更清晰，变量命名更规范
  - 增强了日志输出（进度、等待时间、异常提示）
  - 更好的错误提示和用户引导
  - 兼容性保持不变（完全兼容原有 ComfyUI 工作流）

### 🛠️ 技术细节
- 使用 `get_http_session()` 工厂函数统一管理所有请求
- 强化了对 Agnes V2.0 API 的适配性
- 保留了双解码方案（OpenCV + imageio）

### 📋 使用建议
- 推荐先使用较低参数（81帧 + 768×512）进行测试
- 如仍出现网络问题，建议切换网络环境（关闭VPN/使用手机热点）

## 安装教程
### 方式1：ComfyUI Manager 一键安装（插件上架后可用）
1. 打开 ComfyUI Manager → Install Custom Nodes
2. 搜索插件名：`xiaomo-agnes-video`
3. 点击 Install，等待自动安装依赖 `requests`，重启ComfyUI生效

### 方式2：手动离线安装
1. 打开 ComfyUI 目录下 `custom_nodes` 文件夹
2. 执行Git克隆命令：
```bash
git clone https://github.com/suziran7991-hue/comfyui-xiaomo-agnes-video.git
```

## GitHub访问超时/443端口连接失败解决办法
### 1. 全新安装使用镜像加速克隆（推荐）
打开 custom_nodes 目录CMD执行：
```bash
git clone https://mirror.ghproxy.com/https://github.com/suziran7991-hue/comfyui-xiaomo-agnes-video.git
```
### 2. 已安装插件更新失败
进入插件文件夹执行：
```bash
git remote set-url origin https://mirror.ghproxy.com/https://github.com/suziran7991-hue/comfyui-xiaomo-agnes-video.git
```
```bash
git pull
```
### 3. 镜像依旧无法连接（离线备用方案）
1. 前往项目主页点击 Code → Download ZIP 下载源码压缩包；
2. 删除原有 comfyui-xiaomo-agnes-video 文件夹；
3. 解压压缩包，文件夹重命名为 comfyui-xiaomo-agnes-video 放入 custom_nodes；
4. 重启ComfyUI完成更新。
## 使用说明
在输入框 肖默_API密钥 填写你个人的 Agnes 平台 API Key
肖默_图片公网HTTPS链接 填入图床上传后的公开图片地址，本地图片文件路径无法读取，必须填写公网图片链接
帧数仅支持标准数值：81、121、241、441，其他数字会弹窗提示错误
正向提示词描述画面运动、镜头风格；反向提示词屏蔽崩坏、闪烁、变形等问题
输出端口1：原生VIDEO视频流，直连预览/保存节点自动导出MP4；
输出端口2：完整任务JSON日志，用于查看接口原始数据、排查报错

- 1. 打开ComfyUI根目录（python_embeded所在的文件夹）CMD，执行：

D:\ComfyUI\python_embeded\python.exe -m pip install requests>=2.30.0

- 3. 若以上都无效，直接运行启动脚本内置Python：
# 双击 run_nvidia_gpu.bat 启动ComfyUI，在弹出的黑窗口输入：

pip install requests>=2.30.0
